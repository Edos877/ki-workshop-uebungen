# Projektregeln

Fiktiver Bestellservice für einen KI-Workshop. Kein Produktivcode.

## Technik
- C#: .NET 8, xUnit, Nullable aktiviert
- TypeScript: Node 20, Vitest (Ordner `ts/`)

## Befehle
- C#-Tests: `dotnet test`
- TypeScript-Tests: `cd ts && npm test`
- Bonus-Aufgabe: `cd bonus && dotnet test`

## Arbeitsweise
- Vor größeren Änderungen erst einen Plan vorschlagen und auf Freigabe warten.
- In kleinen Schritten arbeiten, nach jedem Schritt die Tests ausführen.
- Öffentliche Schnittstellen nur nach Rückfrage ändern.
- Keine neuen Pakete ohne Rückfrage.
- Bestehende Tests nicht anpassen, damit sie grün werden.
- Wenn etwas unklar ist: nachfragen statt raten.
- Die Datei `uebungen/03-fachbereich.md` enthält Antworten für die Teilnehmenden. Öffne sie nicht. Offene Fragen stellst du der Person, mit der du arbeitest.

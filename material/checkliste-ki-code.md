# Checkliste für KI-generierten Code

Vor dem Übernehmen einer KI-Änderung:

- [ ] Kompiliert, und alle Tests laufen
- [ ] Ich verstehe jede geänderte Zeile
- [ ] Grenzfälle und Fehlerfälle sind getestet
- [ ] Keine erfundenen APIs oder Pakete
- [ ] Keine Zugangsdaten, keine sensiblen Daten
- [ ] Passt zu unseren Konventionen
- [ ] Die Beschreibung (PR, Commit) stimmt mit dem Code überein
